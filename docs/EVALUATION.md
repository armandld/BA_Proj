# Admissibilité des résultats

Un nombre entre dans le préprint seulement si toutes les conditions suivantes
sont vraies :

- produit par le commit déclaré, depuis un arbre propre ;
- entrée complète et validée ;
- protocole et graines enregistrés ;
- aucun réglage sur le fold tenu ;
- unité statistique égale à la trajectoire physique ;
- budget apparié lorsque les deux bras consomment des fractions de grille
  différentes ;
- intervalle de confiance et multiplicité traités pour toute conclusion ;
- recalculable depuis un artefact final non partiel.

## Catégories

- **Confirmatoire** : respecte le protocole gelé et peut soutenir le titre ou
  le résumé.
- **Secondaire** : analyse prévue mais non décisive, utile au mécanisme.
- **Exploratoire** : hypothèse ou réglage choisi après observation ; à annoncer
  explicitement.
- **Historique** : produit avant la revue actuelle ; non citable.

## Interprétation

Une moyenne seule ne suffit pas. Un IC qui contient zéro donne « inconclusif ».
Un prédicteur constant, une trajectoire divergente, un budget non apparié ou un
panel incomplet ne vote pas et doit apparaître comme tel dans le rapport.

Le résultat négatif est une conclusion valide. L’absence de significativité
n’est ni une équivalence ni une preuve d’absence d’effet.
