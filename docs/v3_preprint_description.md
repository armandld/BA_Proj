**Status:** complete description of the executed V3 study (Tasks 0–10 of
`docs/protocol_v3_evaluation.md` §8.3), written for drafting a preprint.
This document records *what was done, how, and what came out*. It does
**not** interpret the findings: implications, the quantum-advantage
narrative, and the manuscript discussion are deferred (thinking task for

named `.npz` outputs, or to the verification probes in §8.

Headline reproducibility: the whole study regenerates from one command,

(`t10_aggregate.py`) confirms **51/51 headline numbers reproduce
(OK=51, DIFF=0, MISSING=0)** at tagged commit `ca7f815`. The test gate is
**118 pytests** (`tests/v3/`), all passing, re-verified independently in a
second environment (§8.5).

## 1. System under study

**Q-HAS** is a hybrid quantum–classical adaptive mesh refinement (AMR)
framework for 2-D resistive magnetohydrodynamics (MHD). Two code layers
exist and are held read-only by the protocol:

- **V1 (`src/`)** — the production pipeline. A 2-D incompressible MHD
  solver (4th-order finite differences in space, RK4 in time, spectral
  divergence-free projection of **v** and **B**; `src/Simulation/`), and
  a QAOA stack (`src/VQA/`) that maps local fields to a per-edge Ising
  Hamiltonian and selects patches to refine from its ground state.
- **V2 (`study/`)** — a falsification study (phases 1→13) that generates
  DNS snapshots, defines a per-patch "hard to coarsen" label, builds
  Ising Hamiltonians from physical features, and bounds the approach with
  gradient-boosted-tree (GBT) surrogates under random-split and
  leave-one-scenario-out (LOSO) evaluation.

The object under test is a **local-Ising / QAOA refinement criterion**:
a decision rule `refine(patch i) = f(local MHD fields at i)`, realised as
the ground state of an Ising Hamiltonian `H = Σ_i h_i Z_i + Σ_{ij} C_ij
Z_i Z_j + Σ_p K_p Z_iZ_jZ_kZ_l` whose coefficients are functions of the
fields. The question: does this criterion carry value beyond the
classical multi-indicator AMR baseline, and if not, *what* fails —
representation, selection, prediction, or closed-loop behaviour?

**Grid / qubit topology.** A snapshot at resolution N is partitioned into
`dim × dim` patches. Each patch boundary carries refinement "links":
qubits `0..dim²−1` are horizontal links H(i,j), qubits `dim²..2dim²−1`
are vertical links V(i,j). The Hamiltonian places `Z` biases on links,
`ZZ` couplings along shared rows/columns, and `ZZZZ` couplings on
plaquettes; the exact index map is
`src/VQA/cost_hamiltonian.create_period_hamiltonian`.

**Scenarios (8).** The 4 original instability classes (Orszag–Tang,
Harris tearing, Kelvin–Helmholtz, MHD rotor) plus 4 added in Task 8
(Lamb–Oseen vortex, island coalescence, double tearing, magnetic twist).
**Re = Rm ∈ {400, 800, 1200, 1600}**, N = 256.

## 2. Pre-registered protocol (design)

The protocol (`docs/protocol_v3_evaluation.md`) was frozen before any new
computation. Its design principles:

1. **Three nested levels**, cheapest first; a lower level can only *rule
   out*, only Level 3 can *rule in*.
   - **L1 (static):** is instantaneous feature information sufficient?
   - **L2 (predictive):** does temporal information add value at horizon
     h > 0?
   - **L3 (closed-loop):** does any of it matter inside the running
     pipeline? *(out of scope of this brief; separate spec.)*
2. **Continuous quantities first, thresholds second.** Binary labels and
   F1 are secondary, robustness-checked views.
3. **Claims about families require a proof or an exhaustive search, never
   an ERM learner.** A learner's out-of-distribution score is a statement
   about the *selection procedure*, reported as such.
4. **The unit of statistical replication is the trajectory** (one
   scenario × Re × physics seed), never the snapshot.
5. **All headline numbers come from one tagged commit**, regenerated by
   one script; both score aggregations (block_avg, block_max) are always
   reported side by side.

### 2.1 Common ground

- **Primary quantity (continuous):** per-patch coarsening error `e_i(t)`
  = relative L2 distance between the fine fields and their block-averaged
  reconstruction over the patch, normalised by the global field RMS
  (phase 2 `patch_l2_errors`).
- **Secondary quantity (dynamic):** per-patch evolution error
  `d_i(t; δt)` — the L2 difference at t+δt between the field evolved at
  full resolution and the field evolved with patch i alone held coarse
  (Task 6).
- **Binary views (secondary):** `y_i = 1{e_i > P_75}`, prevalence 0.25 by
  construction.
- **Baselines (mandatory in every table):** B1 classical score
  block_avg (V1 convention); B2 classical score block_max (V2
  convention); B3 refine-all / refine-none degeneracy floors; B4 GBT on
  all 9 features (ERM reference); B5 GBT on `score_classical` alone; B6
  learned linear H (phase 11c); B7 random ranking.
- **Metrics.** Primary: **captured-error-at-budget** `CE(b) = Σ_{i∈top-k}
  e_i / Σ_i e_i` for budget b ∈ {0.10, 0.25, 0.50} (rank by method score,
  refine top k = ⌈bn⌉), plus the CE-curve AUC — threshold-free, matching
  the V1 cost trade-off. Secondary: Spearman ρ(score, e_i); F1 at p75 with
  degeneracy flags.
- **Statistics.** Block bootstrap at trajectory level (B = 1000,
  percentile CIs); snapshot-level resampling forbidden for headline
  claims. Paired comparisons report mean Δ, 95% CI, and the fraction of
  trajectories with Δ > 0.

### 2.2 The 9 instantaneous features

Per patch at `dim × dim` resolution: `score_classical` (the existing AMR
indicator), |v|², |B|², |ω_z|, |J_z|, |∇v|², |∇B|², det(∇B) (X-point
indicator), Re (scalar broadcast). Source: `phase11_upper_bound.
extract_features_2d`.

## 3. Common machinery (Tasks 2, 3)

These are pure libraries, validated by pytest (no DNS data needed); they
are imported by every analysis task.

**`study/v3/metrics.py` (Task 2).**
- `captured_error_at_budget(scores, e, budgets)` → `{b: CE(b)}` and the
  CE-curve AUC (trapezoid on [0,1] with CE(0)=0). Ranking by descending
  score, stable argsort; returns NaN if Σe = 0.
- `spearman(scores, e)`; `degeneracy_floors(p)` (refine-all F1 =
  2p/(1+p), refine-none F1 = 0); `degeneracy_flag(pred, prevalence,
  tol=0.005, gt=None)` implementing §1.3-B3.
- *Acceptance:* hand-computed 6-patch example (CE = 0.5/0.6/0.6, AUC =
  7.4/12); refine-all floor verified analytically against sklearn F1 for
  p ∈ {0.25, 0.319}; 15 tests.

**`study/v3/stats.py` (Task 3).**
- `bootstrap_by_trajectory(values, traj_ids, B=1000, statistic, seed,
  ci)` — resample trajectory IDs with replacement, recompute the
  statistic on pooled values, percentile CI.
- `paired_delta_bootstrap(values_a, values_b, traj_ids, …)` — per-
  trajectory deltas Δ_t = stat(a_t) − stat(b_t), bootstrap over
  trajectory IDs; reports mean Δ, 95% CI, fraction Δ > 0.
- *Acceptance:* on maximally autocorrelated synthetic input (constant per
  trajectory, T=50, m=10) the bootstrap std matches the analytic SE
  std(effects)/√T to 0.4 % (0.1401 vs 0.1407), and the trajectory-level
  CI is **3.06× wider** than the (forbidden) snapshot-level CI
  (theoretical √m = 3.16); 10 tests.

| B2 classical (block_max) | 0.517 | 0.195 | 0.375 | 0.631 | 0.582 | 0.365 |

### 4.4 Task 9 — Proposition-2 strict mean-field condition

`study/v3/t9_prop2_check.py`. For every snapshot of every (scenario, Re,
seed) trajectory, builds both patch Hamiltonians via the imported
`build_patch_hamiltonian` (V2 parameter-free, c_bias=1.0, thr=0.15; V1
with the `TRAINED_*` trial-4 parameters) and evaluates the pre-registered
per-site condition

> Σ_{j∋i} 2|C_ij| + Σ_{p∋i} 4|K_p| < |h_i|

over the 2·dim² edge-qubits, with topology mirroring
`create_period_hamiltonian` exactly. When the condition holds at site i,
the exact ground state is s_i* = −sign(h_i) — i.e. the decision is
strictly per-site. Reports the fraction of sites satisfying the strict
condition.

Fraction of sites satisfying the condition (mean over snapshots):

| dim | V1 mean | V2 mean |
|---|---|---|
| 2 | 0.008 | 0.034 |
| 4 | **0.221** | **0.000** |

V1 at dim=4 is strongly scenario-dependent (harris 0.47–0.70,
magnetic_twist 0.38–0.60, island_coalescence 0.45–0.52; ≈ 0 for
lamb_oseen / rotor / double_tearing). V2 is exactly 0.000 on all 32
dim=4 configs.

- *Acceptance: PASS* (table delivered; pytest 9/9, including an
  exhaustive 256-state Ising minimizer that *proves the Proposition
  numerically*: condition-everywhere ⇒ exact ground state = −sign(h),
  plus a strong-coupling counterexample).
- **The V2 = 0.000 is verified real — see §8.** It is a structural
  consequence of V2's normalisation, not a bug.

### 5.1 Task 5 — phase-11E rerun, fixed (signed ψ, dual aggregation)

### 5.2 Task 6 — dynamic ground truth d_i (pilot)

`study/v3/t6_dynamic_gt.py`. For each selected snapshot and each patch i:
build the variant where patch i alone is block-averaged + prolonged
(`coarsen_patch_window`, verified against phase-2 `coarsen_field`), evolve
reference and variant with the imported `MHDSolver.step_full` for
δt = 0.1, take the phase-2-normalised relative L2 difference of the full
fields at t+δt. **CFL fairness:** the dt sequence is recorded during the
reference evolution (`adapt_dt(0.4)`, last step truncated to land exactly
on δt) and **replayed bit-identically** for every variant, so the two
runs differ only by the patch-coarsening perturbation.

Pilot (N=128, orszag_tang Re=400, 2 snapshots, all 16 patches): completes
in ~13–23 s/snapshot; **Spearman(d_i, e_i) = 0.989** (n = 32) — the static
coarsening error is a near-perfect ranking proxy for the dynamic
evolution error at δt = 0.1 on this config.

- *Acceptance: PASS* (pilot completes, ρ > 0; pytest 9/9, including a real
  miniature-solver integration test where constant-field patches give
  d = 0 *bit-exactly* via the dt replay and argmax(d) = argmax(e)).
- **Cost projection (§8.4 gate):** ~20 s/snapshot at N=128, ×(256/N)³ = ×8
  scaling → full N=256 campaign (16 configs × 10 snaps) ≈ 4.6–7.2 h on the
  workstation (not launched in this brief).

## 7. Protocol deviations (logged)

`docs/protocol_deviations.md`:

- **D1 — KH physics-seed amplitude.** §1.1 specifies "amplitude noise at
  the V1 perturbation level." For kelvin_helmholtz only, the amplitude is
  **0.005** (other 7 scenarios 0.1). At 0.1 the injected fluctuation
  energy is ≈ 20× the structured KH perturbation and dilutes the measured

## 8. Verification of zero-valued and load-bearing results (triple-check)

Concern: an exact value like 0.000 could be a code error or a bad

### 8.1 Task 9 V2 = 0.000 (dim=4) — the load-bearing scientific zero

This is the only 0.000 that is a *scientific claim about the Hamiltonian*
(not a binary-F1 degeneracy). Verified four ways, in a clean environment
with freshly generated DNS snapshots (not the saved `.npz`):

1. **Analytic prediction.** V2 sets `h_i = c_bias·median_scale·(score_i −
   0.15)` where `median_scale` is the *median magnitude of the couplings*
   and `score ∈ [0,1]` ⇒ `|h_i| ≤ 0.85·median_scale`. The per-site LHS
   sums ~4 incident couplings (each ~median_scale; ZZ weight W_ZZ=2
   dominates ZZZZ weight W_ZZZZ=1) ⇒ LHS ≈ 12–16·median_scale. So
   `LHS < |h_i|` requires `|score−0.15| > ~12`, impossible for a bounded
   score. The condition is structurally unsatisfiable for V2.
2. **Numerical confirmation, real Hamiltonians.** Built V2 at dim=4 on
   real OT/harris/double_tearing snapshots: `|h|` median ≈ 0.1–0.5, LHS
   median ≈ 12–16, **LHS/|h| ratio 14–85, never below 1** → 0/32 sites,
   with a 13–85× margin (not borderline).
3. **|h| construction exact.** At N=256, the predicted
   `|h|max = median_scale·|score−0.15|max` matches the actual `|h|max` to
   four decimals (0.8002 / 0.6696 at dim 2/4) — the bias is exactly the
   claimed form.
4. **Independent bookkeeping + internal control.** A from-scratch
   recomputation of LHS and h (no shared code with `per_site_condition`)
   **matches exactly in all 12 probe cases**. The same checker returns
   *nonzero* for V2 at dim=2 (double_tearing 0.4 in the published run) and
   discriminates V1 by scenario (harris 32/32 satisfied at dim=4, OT
   1/32, double_tearing 0/32 — matching the published 0.70/0.07/0.00) —
   so it is **not stuck-at-zero**. The exhaustive 256-state ground-state
   test confirms the Proposition's logic itself.

**Conclusion:** V2 = 0.000 is a correct, robust, reproducible consequence
of V2's coefficient normalisation (the bias is scaled to ~one typical
coupling while the sufficient condition sums all incident couplings). It
is *not* an artifact.
